# The-Galaxy-Project
Welcome to the Galaxy Project

An open source project with one goal: to bring every catalogued galaxy into SpaceEngine, each at its real position in the sky and its real distance from Earth.

The project already holds just under 150,000 real galaxies, from the dwarfs orbiting the Milky Way to the most distant galaxies ever seen.

Plan:
The project is open source
Plan on adding way more galaxies
Plan on fixing up the different clusters
Plan on adding models to the more interesting galaxies (Example: RCP 28)
Plan on adding black holes to galaxies that deserve it (Example: RCP 28)
